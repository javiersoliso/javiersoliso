## Hi, I'm Javier Solís

Final-year Mechatronics Engineering student at Universidad ECCI in Bogotá, Colombia. I build **biosignal instrumentation, embedded systems and open hardware**, and I'm working towards brain-computer interfaces.

I like projects that end in a number: a measured error, a debugging log with voltages, a simulation that can be rerun. Each repository below says what works, what was measured and what is still missing.

### What I'm working on

**Open 16-channel electroencephalography (EEG) and electrocardiography (ECG) acquisition board** (in development). It uses two ADS1299 24-bit analog front ends, runs on battery power and streams in real time, with the open OpenBCI Cyton and Daisy designs as reference. Current stage: analog front-end definition and the test plan (input-referred noise, common-mode rejection, alpha reactivity).

### Selected projects

| Project | What it is |
|---|---|
| [**rESPira**](https://github.com/javiersoliso/rESPira) | Open photoplethysmography and breathing instrument (ESP32, Android, Python) that shows heart-breathing coupling in real time. Tested in a 144-minute overnight session, with its error figures published. *(in Spanish)* |
| [**led-cube-8x8x8-stm32**](https://github.com/javiersoliso/led-cube-8x8x8-stm32) | 512-LED cube on an STM32 NUCLEO-F746ZG programmed at register level, with a live 3D web simulator and a debugging log with bench measurements. |
| [**termoguajira-energy-system**](https://github.com/javiersoliso/termoguajira-energy-system) | Replacing a 130 MW coal unit with fuel cells, solar and batteries: hourly simulation in System Advisor Model and a 2,271-case parameter sweep on public grid data. |
| [**isa51-pid-generator**](https://github.com/javiersoliso/isa51-pid-generator) | Piping and instrumentation diagram of an industrial polypropylene filament spinning line to the ISA-5.1 standard, generated from Python: 16 control loops, four revisions. |
| [**servo-arm-mujoco**](https://github.com/javiersoliso/servo-arm-mujoco) | 4-degree-of-freedom servo arm simulated in MuJoCo and trained with reinforcement learning, as the design stage for a physical arm. |
| [**bar-bender**](https://github.com/javiersoliso/bar-bender) | Automatic bar bender: actuator sizing, servo drive parametrization, budget and a fully computer-generated animation in Blender. |
| [**palletizer-animation**](https://github.com/javiersoliso/palletizer-animation) | Presentation video of a rice palletizing line: animation, materials, lighting and rendering in Blender. |
